# Security policy

Supported public source snapshot: `0.1.0-rc1`.

Do not report vulnerabilities in a public issue. Use the owner-confirmed
security contact `security@lumaquant.tech` with the subject prefix `[SECURITY]`.
The owner attests that the mailbox is active, monitored and has passed a test
reception; independent mailbox verification was not performed. No response-time
SLA or 24/7 coverage is claimed. Include the affected version, impact and
reproducible steps, but never include credentials, wallet recovery material,
customer data or production records.

This repository has not received an independent third-party audit. A report must
not claim that LUMA Quant is fully audited, guaranteed secure or compliant with
a legal regime without the corresponding independent evidence.
